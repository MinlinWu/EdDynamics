# Conditional predictor comparisons

This workflow compares the frozen four-term mechanism with a calibrated three-constant accounting predictor (`C3`), a ridge conditional-mean predictor (`ARX`), persistence and zero signed input. It preserves the original coordinates, cohort splits, frozen six-state partition and conditional one-step evaluation. These post hoc supplementary comparisons assess recovery within the specified model framework; they do not identify a unique causal mechanism or an autonomous trajectory generator.

## Inputs and dependencies

Use the original EdDynamics Python environment and install any missing dependencies from `requirements.txt`. Supply the output root generated by the original repository workflows. Required artifacts include the Stage-1 panels and frozen partition, the frozen Stage-2 implementation and model, confirmation predictions, original uncertainty summaries, and all six neural-model prediction exports. The source and recovery identities are registered in `source_contract.json`.

The implementation loads the original frozen Phase-1 source from the supplied output tree. It checks the registered source version, model manifests, cohort identities and prediction keys before using the arrays. The narrowly specified partition-export and four coordinate-value recovery records preserve the original numeric evaluation; they neither refit the partition nor apply general rounding or snapping. An unrecognized change stops execution.

## Commands

Run from the repository root, replacing each placeholder. Choose a fresh result root for the public implementation; existing execution receipts bind to their original source hashes and must not be relabelled.

```bash
PYTHON=python
HISTORY=/path/to/outputs_KT4
RESULT=/path/to/conditional_baseline_results
CODE=s2_minimal_mechanism/robustness/conditional_baselines

$PYTHON "$CODE/run_fourterm.py" tests --output-root "$HISTORY"
$PYTHON "$CODE/run_fourterm.py" check --output-root "$HISTORY" --run-root "$RESULT"
$PYTHON "$CODE/run_fourterm.py" smoke --output-root "$HISTORY" --run-root "$RESULT" --threads 8 --bootstrap-workers 4
$PYTHON "$CODE/run_fourterm.py" all --output-root "$HISTORY" --run-root "$RESULT" --threads 8 --bootstrap-workers 4
```

The smoke output is the sibling directory named `<RESULT>_smoke`. Formal execution requires a matching smoke receipt. `both` runs smoke followed by formal execution. Changing the computational source or frozen inputs prevents reuse of prior stages. Output completion records indicate technical completion, independently of the direction of the findings.

For an end-to-end synthetic integration check, use a new empty directory:


## Models and statistical definitions

- The original four-term model remains frozen. `C3` and `ARX` use the same twelve state/accounting and observed-interval predictors. The fitted models do not use confirmation users for fitting or selection. Development fits and final pooled-development fits are stored separately.
- `C3` minimizes the training population-field squared distance on the shared accumulator scaffold. `ARX` uses standardized interval ridge regression, with its penalty selected by the original five-component validation score. Transition outcomes are not a separate fitting target.
- The original field grid has 40 by 40 cells on `[-1,1]^2` and a minimum of 30 intervals per supported cell. Fields assign each eligible learner total mass one. Main interval errors are interval weighted; user-equal errors are separate summaries. Six-state transition matrices use interval counts followed by row normalization.
- Seed 42 defines 2,000 paired whole-learner bootstrap draws. The complete learner contribution, including resampling multiplicity, is shared across models. The two primary contrasts are the accounting or linear predictor's field squared distance minus the four-term distance. Their fixed-support nominal 97.5% basic intervals cover the two designated comparisons within this block. Other levels, methods and support reselection are reported separately.
- Cross-model comparisons use six frozen neural runs: 42, 2026, 666, 606, 37 and 4669. The representative seed has paired learner uncertainty; cross-seed variation is a separate quantity. Common-reference field correlation does not establish shared internal mechanisms or amplitude calibration.
- Nonfinite estimates remain unavailable. Bootstrap mean, bias, standard deviation, finite draw count and interval-method disagreements are retained. Nominal intervals do not establish validated coverage, and intervals containing zero do not establish equivalence.

| Directory or file | Contents |

| `models/final_models.json` | Frozen conditional predictors and training/selection definitions |

| `cross_model/` | Six-run field correspondence and seed-42 paired comparisons |
| `existing_evidence/` | Original model-family and matched-method uncertainty summaries |
| `final/numeric_report.md` | Numerical summary with conditional scope and mixed results |
| `final/COMPLETE.json` | Technical completion record |

The four-term family can improve total field recovery while a simpler predictor improves individual components or transitions. All of these results are retained. The component decomposition describes the model calculation, not causal contributions to learner behaviour. The original innovation-reassignment reference and the separate response-generating controls are different estimands and are not substituted for one another.

Mathematical definitions are documented here. See the repository's supplementary source manifest for correspondence with the source versions used for the archived results.
