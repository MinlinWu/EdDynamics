# Supplementary extraction

Run only after all required primary, robustness and cross-analysis outputs are complete. Execute every command in `scripts/README.md`.

The [statistical reporting workflow](scripts/statistical_closure/README.md) reads saved residence-time draws (Supplementary Table 4), matched Event-SSL fits (Tables 7–8) and field and transition resampling summaries (Table 11). Its [launch commands](scripts/README.md#statistical-reporting-from-preserved-outputs) also collect uncertainty estimates from the conditional-baseline and common-reference analyses (Note 8 and Table 13). Results are written to a separate reporting directory.
